Multi-Agent Orchestration

LangGraph Multi-Agent State Graph

Decoupled clinical reasoning agents with intermediate routing policies and dynamic state transitions.
Node 1 • Ingestion
Timeline Segmenter
Extracts chronological stages: Admission → Hospital Course → Discharge. Resolves event statuses (active, resolved, worsening).
Node 2 • Retrieval
Differential Agent
Matches timeline findings against clinical guideline vectors. Re-ranks candidate diagnoses using learned linear feature weights.
Node 3 • Quality Gate
Contradiction Agent
Audits cross-sectional record for status reversals, missing admission symptoms, and unannounced new discharge findings.
Node 4 • Calibration
Confidence Agent
Executes 8 perturbed passes to compute prediction variance (uncertainty) and runs logistic calibrator for true probabilities.
Node 5 • Synthesis
Meta Agent
Synthesizes validated timeline, contradiction evidence cards, and calibrated differentials into final structured JSON.
